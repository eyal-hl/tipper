# tipper

A sideways-phone meme of a tip screen. Nothing is charged. The buttons just react.

Hold the phone sideways. Upright, it tells you to put it back on the counter.

Leave it alone and the percentages creep up. No Tip runs away three times, then the curse lands. After 15% is declined the screen gets meaner and 18% can fail too. Tap the bill for the check. A real tip brings dessert and a second round. Hold a button and it comments. Next customer shows a report card.

Each button still has ten outcomes and shows a new one until it has used the set.

- **15%** has two decline outcomes. Those gray the button out.
- **No Tip** has ten curses.
- **18% / 20% / 30%** each have ten receipts. Some 30% receipts can be talked into 45%.
- **Custom** roasts while you type, then picks from ten reactions for that size of tip.
- The back arrow is not an exit.
